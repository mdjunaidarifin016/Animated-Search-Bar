# 🔍 Animated Search Bar

A simple and stylish animated search bar built using **HTML and CSS**. The search bar smoothly expands when clicked and collapses when clicked again.

## ✨ Features

- Smooth expand and collapse animation.
- Pure HTML and CSS implementation.
- Checkbox-based interaction using CSS selectors.
- Font Awesome search icon.
- Custom background and styling.
- Responsive layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome 7
- Google Fonts

## 📸 Preview

The search bar starts as a circular search button and expands into a full search input when clicked.
